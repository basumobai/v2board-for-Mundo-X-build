# 管理后台视觉方向（待审）

## 目标

旧管理后台是预编译的 Umi/Ant Design 页面。此轮只调整已有的自定义 CSS，
不改变业务逻辑和接口。视觉上以浅色内容、明确的文字层级和轻盈的导航为主。

Apple 对 Liquid Glass 的说明强调：玻璃是浮在内容上的导航与控件层；
内容表格保持清晰，避免玻璃叠玻璃；高光、边缘、阴影和透底共同表达厚度，
并且需要在降低透明度、减少动画时保持可读。

参考：
- https://developer.apple.com/videos/play/wwdc2025/219/
- https://developer.apple.com/design/human-interface-guidelines/materials
- https://github.com/sunyuchentrx/v2board-admin/tree/main/docs/screenshots

## 在当前后台里的取舍

- 默认的浮动侧栏与顶栏使用浅色材质、细边缘高光和轻阴影；菜单选中项使用浅色填充。
- 主动选择暗色侧栏或顶栏时改用实色深蓝灰，保持配置选项有效。
- 表格、表单、卡片保持实色底。数据阅读优先于材质效果。
- 登录页采用浅色环境光；默认不再出现大面积深蓝黑渐变。
- 主题色只强调主要操作和当前状态，不能把整个界面染色。
- 对不支持 backdrop-filter 的浏览器，半透明底色仍应能看清文字。
- 尊重系统的减少动画、降低透明度及强制高对比度设置。

## 合并前人工验收

在真实管理后台或隔离的测试实例里，分别用桌面和 390px 手机宽度查看：
登录、仪表盘、用户列表、节点列表、编辑抽屉、确认弹窗。还要切换
sidebar/header 的 light/dark 设置与四种主题色，检查文字、图标、遮罩、
横向滚动以及焦点。请附截图后再考虑合并；静态 CSS 检查不等于视觉验收。
